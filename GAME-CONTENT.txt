--------------------------------------------------------------------------
HOW THE THREE TIERS WORK
--------------------------------------------------------------------------

  Player-facing name    Data key    What it means
  Mild                  safe        Plays sober, with anyone.
  Spicy                 night       Adds material for a night out. Drinking assumed.
  Filthy                filthy      Adds what you would only admit to people who
                                    will not repeat it.

  TIERS ADD, THEY DO NOT REPLACE. Spicy = Mild + Spicy. Filthy = all three.
  So an entry only needs to appear in the LOWEST tier it belongs to, and
  moving an entry down a tier makes it show up for more tables, never fewer.

  A tier marked "none written" is not a gap in the game — that mode simply
  plays the tiers below it.

  Two layout policies decide the ORDER a tier is dealt in (see data/pools.ts):
    supplement — dealt blind, order never seen (most games)
    lead       — browsed in a picker, so spicier tiers are dealt one-for-one
                 from the top rather than stacked above everything else
